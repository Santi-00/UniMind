# Changelog

## 1.0.0
- Study in sequence: split a document into chapters and generate one lesson per chapter, then study them in order.
- Backup, restore and data export (JSON + Markdown lessons); automatic daily backup.
- Local profile and a richer dashboard (preparation per subject, latest tests, exams).
- Subject pages (materials, lessons, tests and progress in one place).
- Math formulas rendered with KaTeX (the AI writes LaTeX).
- New "glass" interface.
- Better error messages from Ollama; ChromaDB telemetry disabled.

## 0.x
- Subjects, schedule, document upload and text extraction, local RAG, AI tutor with sources, lessons, tests, progress and study plans.
